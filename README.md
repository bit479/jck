# 特变电工进出口公司全球业务展示系统

本项目是面向平板横屏、企业展厅讲解和内部业务展示的静态互动网站。

当前已完成开头导览页面：

- 深蓝色科技风格背景
- 网站中英文标题和概括文字
- 公司简介、海外项目建设、海外矿业开发、未来展望四个大型入口
- 点击入口后切换到对应页面

同时已完成：

- 顶部固定导航栏
- 四个栏目切换按钮
- 返回导览按钮
- 全屏展示和退出全屏按钮
- 公司简介占位文字、业务标签和占位图片框
- 海外项目建设页面的真实世界地图基础版本
- 根据经纬度计算位置的塔吉克斯坦项目节点
- 海外项目建设页面的八个国家节点
- 可配置的国家标签偏移，减少相邻标签重叠
- 海外矿业开发地图，以及塔吉克斯坦和赞比亚两个金色节点
- 未来展望地图和空心节点样式预留
- 三个地图栏目共用同一份地图模板和渲染逻辑
- 国家项目介绍弹窗（支持关闭按钮、遮罩和 ESC 关闭）
- 页面与弹窗的基础淡入效果
- 国家节点呼吸效果和按钮按压反馈
- 中国业务起点至当前栏目目标国家的弧形连接线
- 支持 `prefers-reduced-motion`，减少动态效果时自动关闭动画

复杂动画和粒子效果尚未开发。

## 如何在电脑上打开

1. 打开项目文件夹。
2. 找到根目录中的 `index.html`。
3. 双击 `index.html`，系统会使用默认浏览器打开页面。

也可以右键点击 `index.html`，选择 Chrome、Edge 或其他现代浏览器打开。

## 当前文件说明

- `index.html`：网站页面基础结构。
- `css/style.css`：网站基础视觉样式。
- `js/data.js`：集中保存可修改的文字、国家和项目数据。
- `js/script.js`：生成导览入口和顶部导航，使用同一套逻辑渲染三个地图栏目，并控制项目弹窗。
- `assets/images/company/`：公司 LOGO、公司图片等素材目录。
- `assets/images/projects/`：项目图片素材目录。
- `assets/images/backgrounds/`：背景图片素材目录。
- `assets/videos/`：公司视频素材目录。
- `assets/maps/`：世界地图素材目录。

## 当前地图说明

- 世界地图文件：`assets/maps/world-map.svg`
- 地图数据来源：Natural Earth 1:110m Admin 0 Countries（公共领域）
- 地图投影：等距圆柱投影
- 地图与节点统一使用 `1000 × 500` 坐标系
- 八个国家的经纬度都存放在 `js/data.js` 的 `overseasProjects` 数组中
- 矿业国家存放在 `js/data.js` 的 `overseasMining` 数组中
- 未来关注国家将存放在 `js/data.js` 的 `futureOutlook` 数组中
- 修改经纬度后刷新页面，节点位置会自动重新计算
- `labelOffsetX`、`labelOffsetY` 和 `labelAnchor` 只调整标签位置，不改变节点经纬度
- 塔吉克斯坦项目文字和图片路径位于 `js/data.js` 的 `projects` 数组中
- 当前项目图片文件尚未提供，弹窗会显示“项目图片待补充”
- 未来展望当前没有具体国家，因此地图显示明确的资料待补充提示
